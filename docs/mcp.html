Model Context Protocol (MCP)

MCP connects AI applications to external tools and data through a common protocol.

← All AI engineering topics · Updated November 19, 2026

How it works

  1. An MCP server exposes tools and their input schemas.
  2. The AI application discovers those tools.
  3. The model requests a tool; the application checks and executes it.
  4. The result returns to the model.

Remember: MCP is not just JSON. It standardizes tool discovery and communication. It can operate over HTTP, but is not a replacement for HTTP.

Example: value items in a room

Photo → identify products → look up comparable eBay listings → estimate resale values.

How the eBay tool fits

An MCP server wraps an authorized eBay API integration. The AI application calls the tool to retrieve pricing evidence. Actual sold prices may require separate access and differ from asking prices.

When should I use MCP?

Use MCP when reusable tools or multiple integrations matter. For one simple API, a direct request may be easier.

Security: tools require permissions, validated inputs, and controls on sensitive actions.
