Quick-reference definitions

Vector vs. embedding

A vector is a list of numbers. An embedding is a model-generated vector representing information such as a sentence.

Vector search vs. graph search

Vector search asks which content is close in learned meaning. Graph search follows explicitly stored relationships between entities. They can be combined.

What is cosine similarity?

A comparison of vector directions. Higher similarity can indicate related representations, but it does not establish that two statements agree.

What does the language model do?

It interprets the retrieved text and generates an answer. Retrieval is a separate step; it does not guarantee the answer is accurate.
