Retrieval-Augmented Generation (RAG)

RAG searches source material before a language model answers.

← All AI engineering topics · Updated November 19, 2026

The pipeline

Documents → chunks → embeddings → vector store → retrieve relevant chunks → generate answer.

Why: Retrieved text gives the model specific evidence beyond its training data.

Core terms

Chunk: a small part of a document. Embedding: a numerical representation used to compare content. Vector search: finds similar representations.

Other retrieval approaches

Keyword search uses literal terms; vector search uses learned representations. Hybrid search combines both. Knowledge graphs capture explicit relationships between entities.

Limitations and evaluation

Similar content can still be wrong or contradictory. Compare answers with source passages and track when retrieval fails.

My implementation

My local TaskNest chatbot uses Next.js, 384-dimensional embeddings, LanceDB, and streamed model responses.
