Where can web development and applied AI lead?

An evidence-based, early-career research experiment — not a finished portfolio.

Companion AI/programming research site · GitHub repository

Research question and method

Question: Which early-career roles combine software development with AI, and what portfolio evidence could demonstrate readiness?

Method: Compare three original employer postings, distinguish stated requirements from assumptions, and identify practical projects to demonstrate skills. Sources were checked November 12, 2026.

Limit: A listing's advertised salary is not a guaranteed offer. A missing experience requirement does not prove that a position is entry-level.

Three employer descriptions

1. Netic — Forward Deployed Engineer (FDE), New Grad 2026–2027

Customer-facing AI engineering · New graduate

Responsibilities: Build AI agents, work directly with customers, deploy solutions, improve system reliability, and evaluate AI models.

Compensation: $138,000–$160,000. Location: San Francisco, on-site.

Eligibility: New graduates with a start window between winter 2026 and summer 2027. The posting seeks experience with Python, TypeScript, production systems, LLMs, RAG, and evaluation frameworks.

Gap to investigate: Production monitoring, AI evaluation, and customer-facing engineering experience.

Source: Original Netic posting.

Portfolio audience and design experiment

Reader: Recruiter or technical hiring manager reviewing an early-career software developer.

Direction A — Minimal professional: Short introduction, skill summary, selected projects and contact links.

Direction B — Project-first technical: Project demonstrations, repository links, architecture and tests before the background section.

Provisional choice: Direction B. Evaluate whether readers can identify the strongest project and find its source code quickly.

Visitor stories
