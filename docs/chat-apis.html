Chat Completion APIs

A common interface for sending messages to a language model and receiving responses.

← All AI engineering topics · Updated November 19, 2026

Basic request flow

App → API endpoint → language model → response → app.

Requests typically include a model name and a list of messages (such as system, user, and assistant messages). Responses contain generated content or tool-call requests.

Typical JSON structure
{
  "model": "example-model",
  "messages": [
    {"role": "user", "content": "Hello"}
  ]
}

Illustrative format; exact fields and URLs depend on the provider.

What about streaming?

Streaming delivers partial response data while the model generates it instead of waiting for the full result.

MCP vs. chat APIs

Chat API: talks to a model. MCP: connects an AI application to tools and external data. An application can use both.
