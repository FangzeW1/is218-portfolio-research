## Research question
What early-career opportunities connect web/software engineering with applied AI, and what portfolio evidence would make a candidate credible?

## Audience
Recruiters and technical hiring managers assessing an early-career software developer interested in applied AI.

## Career directions
A. Forward-deployed engineering: customer discovery, integrations, deployment and communication.
B. AI application/platform engineering: APIs, data pipelines, retrieval, testing and reliability.

Current preference for portfolio planning: B, while retaining evidence of customer-facing skills useful for A.

## Design alternatives
A. Minimal professional: concise introduction, skills and contact information, then projects.
B. Project-first technical: featured working projects, screenshots, architecture, test evidence, then background.

Provisional choice: B. It demonstrates capabilities through inspectable work rather than unsupported claims.

## Four visitor stories
1. As a recruiter, I want to understand the candidate's technical focus quickly.
2. As an engineer, I want to inspect project repositories and running demos.
3. As a reviewer, I want to see testing and architecture evidence.
4. As a hiring manager, I want to understand the candidate's role and decisions in each project.

## Initial portfolio evidence
Potential examples: a deployed calculator, TaskNest application work, a tested Python game, and an experimental RAG application. Include only demonstrated functionality and accurate individual contributions.
